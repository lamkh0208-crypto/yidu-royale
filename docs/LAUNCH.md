# 上線檢查清單

## 已完成

- [x] 1–12 人皆可遊玩（不足 4 人補 AI 路人）
- [x] 三層判定退路：AI → 玩家投票 → 規則評分；任何一層失敗遊戲都不會卡住
- [x] AI 供應商備援（Gemini 主模型 → Gemini 備援模型 → OpenRouter）與輪內自動重試
- [x] 斷線重連、房主轉移、房主踢人、伺服器休眠喚醒提示
- [x] 輸入過濾（個資、違規字詞）、提示詞注入防護、單 IP 速率限制
- [x] CSP 等安全標頭、WebSocket 來源檢查、金鑰只在伺服器環境變數
- [x] 隱私與使用說明頁、首頁個資提醒
- [x] 圖示、分享預覽圖、可加入主畫面（manifest）
- [x] 自動化整合測試（`npm test`，推送時由 GitHub Actions 自動執行）、AI 評測（`npm run eval`）、壓力測試（`npm run load`）
- [x] 預先生成的劇本庫（開局不需呼叫 AI）、各供應商分流限速

## 上線前仍需處理（需要人決定或花錢）

- [ ] **AI 額度**：免費層的 Gemini 實測經常回 503（過載）與 429（限流）。正式上線需要付費層。
- [ ] **主機**：Render 免費方案閒置會休眠、重啟會清空房間。正式上線至少要用不休眠的付費方案。
- [ ] **真人實測**：目前只有機器人與模擬手機測試。需要 5–10 位真人玩幾局，確認節奏、音樂與 AI 吐槽的尺度。
- [x] **壓力測試**：100 間房、600 條連線同時進行通過（模擬 AI）。真實 AI 額度仍是瓶頸。
- [ ] **多台機器**：房間存在單一伺服器的記憶體裡，無法水平擴充；要擴充需改用 Redis 之類的共用儲存。
- [ ] **法務**：隱私說明是我依功能寫的初稿，未經法律專業審閱；各 AI 服務條款對送出內容的使用方式需再確認。
- [ ] **金鑰**：開發期間貼在對話中的金鑰應全部重新產生。
- [ ] **內容檢舉**：目前只有房主踢人，沒有玩家檢舉與封鎖機制。
- [ ] **自訂網域**與正式的 Open Graph 絕對網址。
